# 底层安全日志设计

用于规则命中、原操作处理和事后审计。规则 `log=true` 产生现有 `RuleLogRequest`，经第三消息职责交底层日志消费者。`log=false` 仍保留原操作必要完成回执。规则日志保存实际事件、命中来源和提案状态，以及同一原操作的执行结果或错误。

写关闭审计记录已配置目录下可写打开对象的最后引用释放，采集归驱动，原打开仍按文件规则裁决。规则日志与写关闭事实由本模块保存到配置派生的固定本地数据库。具备管理权限的连接经原Main接口按提交顺序分页读取。轮转、保留期限及导出待明确。LLM聊天、工具关系和Ask业务上下文由中间层业务数据库保存。[架构](architecture.md) · [技术契约](technical.md)
