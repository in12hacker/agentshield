# 配置模块产品设计

公共引用：[模块唯一职责](../../architecture.md)。公共定义以链接目标为准，本页不另定义一份。

字段、接口和数据结构见[技术契约](technical.md)，调用关系见[架构](architecture.md)，上下通信见[消息设计](../../contracts/driver-communication/design.md)。

## 一份配置，底层读写

配置模块负责AS配置文件的读取、校验、写入、版本和唯一只读缓存。主模块调用它初始化，并通过公开接口取得驱动所需的持久配置；主模块不重读文件或维护第二份设置。

中间层读取配置或提交带版本的配置内容。配置模块在底层真实保存，涉及驱动的设置由主模块组织下发并确认实际采用。中间层不编辑自保目录，不提交任意文件路径，不取得驱动或维护写权限。

配置文件保存成功与驱动已采用是两项事实。修改命令只有完成保存及必需应用才整体报告成功；失败必须带真实保存版本、实际生效版本和具体原因，不能把发送、入队或改内存当成功。

## 位置固定，内容可管理

部署布局固定为`<自保根>/bin/<后端程序>`。配置模块在自身初始化中一次取得实际执行的后端文件位置，自保根固定为其bin目录的上一层并缓存；不是当前工作目录、启动别名或可修改配置项。

配置、规则文件等在根内使用固定相对位置和文件名。主模块及其他模块不再取得一次目录。规则文件路径由配置模块公开提供，主模块通过MainContext参数转交，但属于只读ConfigPaths，不属于可写配置内容。安装位置在安装时确定；运行期没有修改自保根、配置源或规则源路径的接口。

自保覆盖实际安装根及其后代；底层配置、规则及其他所属模块执行实际修改。驱动验证底层服务进程实例并限定自保写范围，不能按进程名或裸PID放行。普通暂停进程／文件防护不取消自保。

## 真实需要的配置内容

- 格式版本：只接受现行格式，错误或旧字段明确拒绝。
- 固定三职责所需队列容量：接收、慢处理、消息及驱动紧急答复容量；不是让用户配置线程拓扑。
- 普通防护的持久启动默认：进程、文件、网络三类；完整初始化时采用。
- 驱动实际需要的来源资源设置：原操作最大保管窗口和未决容量。
- 固定文件自保拒绝的日志设置；可信自身维护写入由驱动静默快速放行，目录、修改阻断及底层写主体属于固定安全语义，不开放任意路径或宽泛进程白名单。
- 中间层本机连接的允许身份与权限；地址由固定布局派生，不开放默认未鉴权网络监听。

普通匹配规则、询问timeout、容器scope和每条规则log仍在规则文件，不放进AS配置再保存一次。临时开关、实际驱动状态、计数、PID、会话和凭证秘密值不写配置；Flow设置及非秘密凭据绑定复用同一配置所有者，字段见[当前配置契约](technical.md#flow运行时配置)。

## 临时状态与扩展

临时开关由主模块消息接口管理，不写盘；直到手动恢复或AS／驱动重新初始化，重新采用持久默认。普通配置／规则重载保留临时覆盖。

日志、进程树、Flow、凭据绑定与观察范围采用[当前配置契约](technical.md)已接入的设置和固定布局，不把既有消费者重新列为未来占位。未明确的新字段仍不接受空占位配置或任意extras。具体新增字段需要所属模块、类型、含义、保存／采用方式，不能只加一个读不到的开关。

参考成熟软件的配置／规则分离、明确资源容量和自保目标；不照搬数据库调优、学习／permissive模式、云服务或无消费者字段。[fapolicyd配置](https://github.com/linux-application-whitelisting/fapolicyd/blob/main/init/fapolicyd.conf)、[ESET HIPS自我保护](https://help.eset.com/esu/18/en-US/idh_hips_main.html)及[KubeArmor主机文件策略](https://docs.kubearmor.io/kubearmor/documentation/host_security_policy_specification)是具体依据，不代表AS拥有它们全部功能。

公共传参使用[MainContext](../../contracts/main-context.md)，不让规则／驱动模块内部引用配置实现。未明确扩展先[存档](../../archive/unresolved-module-contracts.md)，不以新字段或空接口补齐。
